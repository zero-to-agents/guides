# Zero to Agents: guides

Step-by-step guides for every episode of [Zero to Agents](https://www.youtube.com/@zerotoagents) on YouTube: a practical AI developer setup, built one layer at a time on Mac and Windows. Every command here was run for real on a clean machine.

| Episode | Guide | Platform |
|---|---|---|
| [EP02](guides/ep02-base-layer/) | Terminal, Homebrew and git: the base layer | macos |
| [EP03](guides/ep03-api-keys/) | API keys without leaking them | macos |
| [EP04](guides/ep04-ollama/) | Ollama: your first local model in five minutes | macos |
| [EP05](guides/ep05-model-fit/) | Which local AI model fits your Mac? | macos |
| [EP06](guides/ep06-open-webui/) | A private ChatGPT on your Mac with Open WebUI | macos |
| [EP07](guides/ep07-claude-code-local/) | Claude Code for free, on your own Mac (with Ollama) | macos |
| [EP08](guides/ep08-opencode-codex-local/) | OpenCode and Codex for free, on your own Mac (with Ollama) | macos |
| [EP09](guides/ep09-agents-md/) | AGENTS.md: one file that teaches every coding agent your rules | macos |
| [EP10](guides/ep10-claude-code-hooks/) | Claude Code hooks: a rule your AI agent can't ignore | macos |
| [EP11](guides/ep11-mcp-servers/) | MCP servers: give your AI agent new tools (free, local) | macos |

Tools used in the videos are in [`tools/`](tools/) (for example `ollama-speed.py`, the local model speed test from EP05).

New episodes every week. Found a step that no longer works? [Open an issue](../../issues).
